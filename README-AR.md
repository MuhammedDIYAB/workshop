# دليل رفع موقع ورشة حسن دياب أبو زيد على GitHub Pages

الموقع ثابت (HTML وCSS وصور). ما بحتاج تثبيت أي برنامج ولا سيرفر.

## الملفات اللي لازم ترفعها (18 ملف)
- `index.html`
- `style.css`
- مجلد `images` وفيه 16 صورة
- (ملف `README-AR.md` هذا الدليل، رفعه اختياري)

مهم: لازم `index.html` يكون في المستوى الأول (الجذر) من المستودع، مو داخل مجلد ثاني، وإلا الموقع ما بيفتح.

## الخطوة 1: فك الضغط
1. حمّل ملف `workshop-site.zip` على الكمبيوتر.
2. كليك يمين عليه ثم "Extract All" (ويندوز) أو دبل كليك (ماك).
3. افتح المجلد الناتج. لازم تشوف جواته مباشرة: `index.html` و`style.css` و`images` و`README-AR.md`.
4. لا ترفع ملف الـ ZIP نفسه، وارفع المحتوى اللي بداخل المجلد، مو المجلد الخارجي.
   (ملاحظة: الرفع بالسحب أسهل من الكمبيوتر. من الموبايل ممكن يكون المجلد صعب.)

## الخطوة 2: أنشئ مستودع (Repository) جديد
1. من حسابك على GitHub اضغط **+** أعلى الصفحة ثم **New repository**.
2. اكتب اسم للمستودع بأحرف إنجليزية بدون مسافات، مثلاً `workshop`. هذا الاسم بيظهر بآخر رابط الموقع.
3. اختر **Public**. (ملاحظة: موقع GitHub Pages بيكون علني على الإنترنت حتى لو المستودع خاص.)
4. اضغط **Create repository**.

## الخطوة 3: ارفع الملفات
1. في صفحة المستودع الجديد اضغط **uploading an existing file**. (أو من القائمة **Add file** ثم **Upload files**.)
2. افتح المجلد المفكوك، حدد كل المحتوى بداخله (`index.html` و`style.css` و`images`) واسحبه إلى صفحة GitHub. أو اضغط **choose your files**.
3. انتظر لحد ما تظهر كل الملفات في القائمة وينتهي الرفع. لازم تشوف `index.html` و`style.css` ومجلد `images/` بالأعلى.
4. في خانة **Commit message** اكتب مثلاً: `رفع الموقع`.
5. اختر **Commit directly to the main branch** ثم اضغط **Commit changes**.
6. ارجع لصفحة المستودع الرئيسية وتأكد إن `index.html` ظاهر بين الملفات مباشرة (مو داخل مجلد).

حدود GitHub: لحد 100 ملف بالمرة الواحدة و25 ميغا للملف الواحد. ملفاتنا ضمن الحد (حوالي 1.5 ميغا بالمجموع).

## الخطوة 4: فعّل GitHub Pages
1. من المستودع اضغط تبويب **Settings** (إذا ما ظهر، اضغط القائمة المنسدلة "..." وفيها Settings).
2. من القائمة الجانبية اضغط **Pages**.
3. تحت **Build and deployment** وفي **Source** اختر **Deploy from a branch**.
4. في **Branch** اختر `main`، ثم بالقائمة جنبها اختر **/ (root)**.
5. اضغط **Save**.

## الخطوة 5: تابع النشر وخذ الرابط
1. انتظر دقيقة إلى ثلاث دقائق. حدّث صفحة Settings ثم Pages.
2. لما ينجح النشر بيظهر بأعلى صفحة Pages صندوق مكتوب فيه **Your site is live at** ومعه رابط موقعك. هذا هو الرابط الفعلي، انسخه من هناك.
3. إذا بدك تتابع التقدم: من تبويب **Actions** بالمستودع بتشوف عملية النشر (pages build and deployment). الدائرة الخضراء معناها نجحت.
4. شكل الرابط عادة: `https://اسم-حسابك.github.io/اسم-المستودع/`. الأفضل تنسخه من صفحة Pages بدل ما تكتبه بإيدك.

## إذا الموقع ما فتح أو الصور ما ظهرت
- تأكد إن `index.html` بالمستوى الأول من المستودع، وإن مجلد `images` بنفس المستوى.
- تأكد إن أسماء الملفات بحروف صغيرة كما هي، لأن GitHub بيفرّق بين الحروف الكبيرة والصغيرة.
- جرّب تفتح الرابط بنافذة خفية أو انتظر بضع دقائق وحدّث الصفحة.
- تأكد من Settings ثم Pages إن الفرع `main` والمجلد `/ (root)`.

## التعديل لاحقاً
افتح الملف على GitHub (مثل `index.html`) واضغط أيقونة القلم، عدّل، ثم **Commit changes**. التحديث بيظهر بعد دقيقة أو اثنتين. رقم الهاتف والروابط داخل `index.html`.

## رابط باسم الورشة
الرابط الافتراضي بيحتوي على `github.io`. إذا بدك دومين باسم الورشة، بتحتاج تشتريه وتربطه من إعدادات Pages لاحقاً.
